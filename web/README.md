# NERVE RUNNER - 웹(iPad) 버전

Unity 프로젝트와 **같은 게임 규칙·같은 문제/도감/스토리 데이터**를 브라우저에서 돌리는 버전입니다.
iPad Safari에서 링크(또는 `index.html`)를 열면 바로 플레이할 수 있습니다. 설치·빌드가 필요 없습니다.

## 구성
| 파일 | 내용 |
|---|---|
| `src/core.js` | Unity `Scripts/Core`(순수 C#)의 1:1 JavaScript 포팅: Catmull-Rom 트랙, TrackPathBuilder, CH.1/7/9 전용 코스 + 퀴즈 코스(CH.2–6, 8), StageCatalog, RunnerSim 물리, AutoPilot, 학습 기록 |
| `src/world.js` | 신경계 안을 달리는 3D 월드: 축삭 세포막 터널(별 주변이 탈분극으로 빛남), 말이집·랑비에 결절, 세포체 방(핵·소포체·골지체·미토콘드리아), 가지돌기 가시, 축삭종말 소포, 시냅스 틈새·수용체, 주변 신경섬유 다발·별아교세포·모세혈관, 원경의 뉴런 네트워크, 챕터별 장식(조롱박세포, 피라미드세포, 뇌신경 뿌리, NULL 코어) |
| `src/star.js` | STAR-01 3D 모델 (Tools/VisualPreview의 PuffyStar·표정·ToonRim 포팅) |
| `src/app.js` | three.js 화면, 카메라, UI, 터치 버튼, 배경음악(NRMusic 포팅, WebAudio), 별 음성(기기 한국어 TTS), 슬로모션 생각 시간, 저장(localStorage) |
| `src/body.html`, `src/style.css` | 화면 구성 |
| `build.py` | 위 파일 + `NerveRunner/Assets/NerveRunner/Resources/NerveRunner/*.json`을 하나로 묶어 `index.html`(단독 실행용)과 `dist/nerve_runner.html`(Artifact용)을 만듦 |
| `test/sim_test.js` | Node로 9개 스테이지 자동 주행 → C# SimTests 결과와 비교 |
| `test/pw_test.js` | Playwright로 iPad 화면 크기 스모크 테스트·스크린샷 |

```bash
python3 web/build.py          # 묶기
node web/test/sim_test.js     # 규칙 검증 (C# 테스트와 같은 숫자가 나와야 함)
```

## 2.4 변경 (피드백 반영)
- **정답이 미리 보이던 문제 수정**: 갈림길의 모든 길이 같은 색·같은 모양 입구로 보이고, 정답 길도 휘어 들어가며(덜 휘어서 여전히 지름길), 에너지 오브도 모든 길에 똑같이 놓입니다. Unity C# 코어도 똑같이 바꿨고 C# 테스트 전부 통과.
- **해설이 끊기던 문제 수정**: 다음 문제는 별이 해설을 다 말할 때까지 기다리고, 그동안 레이스가 필요한 만큼만 느려져서 게이트 전에 문제를 읽을 시간이 남습니다.
- **목소리**: 기기에서 가장 자연스러운 한국어 음성(프리미엄/향상됨 > Google > 기본)을 자동 선택, 설정에서 목소리·톤·속도 선택과 미리듣기. 문장을 짧게 끊어 읽고, 말투를 대화체로 바꿈("자, 문제! … 왼쪽은 ○○, 오른쪽은 ○○. 어느 쪽일까?").
- **그래픽**: 실제 신경계 안을 달리는 디자인 + 빛 번짐(블룸) 효과. '가볍게' 품질에서는 블룸과 장식을 줄입니다.

## 2.5 변경 (폰 플레이 피드백)
- **끊김**: 보이는 부분만 그리도록 월드를 160 m 칸으로 나눔(프러스텀 컬링), 폰·태블릿은 블룸 없이 시작, 2초 평균 42fps 아래면 자동으로 화질을 한 단계 낮춤, HUD는 바뀐 값만 갱신.
- **슬로모션**: 기본 0.75배(조금)로 완화, 아무리 느려져도 0.5배 이하로는 안 감. 별은 해설의 핵심 한 문장만 말하고 전체 해설은 [🔊 해설 듣기]/[자세히].
- **문제 창**: 위쪽 얇은 띠로 축소, 폰 화면(높이 520px 이하)에서는 글자·버튼·HUD를 더 작게. 화면 아래 "지금 A ○○" 표시로 내 차선을 바로 확인.
- **도로 폭 1.45배**, 아케이드 드리프트(미니 터보 단계 0.35/0.8/1.4초, 터보 0.9/1.5/2.3초, 드리프트 중 감속 없음, 조향력 증가).
- **EPSP/IPSP 가중 구간(신규)**: 막전위 게이지(-70 mV 휴지). 초록 ＋(EPSP, +7 mV)를 빨리 연달아 모으면 시간적 가중으로 역치 -55 mV 도달 → 활동전위 발화 + 가속, 이후 0.9초 불응기(입력 무시). IPSP 억제 구간에서는 NULL이 막전위를 계속 올리므로 파랑 −(IPSP, −7 mV)를 모아 역치 아래로 지켜야 함(넘으면 '과흥분' 감속). CH.1 가지돌기·CH.7 이마엽·CH.3/4/6/8은 흥분, CH.2(상호억제)·CH.5(조롱박세포)·CH.9(NULL)는 억제 구간.
- 이 변경들은 `NR.TUNE = { width: 1.45, arcade: true }`로 켜져 있고, `{ width: 1, arcade: false }`면 Unity와 같은 규칙입니다(EPSP/IPSP 구간은 웹 전용).

## 조작 (iPad)
- 왼쪽 아래 ◀ ▶ : 조향 · 오른쪽 아래 : 드리프트 / 부스트 / 점프 (여러 손가락 동시 입력 가능)
- 키보드: ←→/AD 조향, Space 점프, Z·↓ 드리프트, Shift·X 부스트, Esc 일시정지

## Unity 버전과 다른 점 (정직하게)
- 웹 버전은 이제 Unity 버전과 다른 '신경계 내부' 디자인을 씁니다(Unity 쪽 뷰는 이번에 갈림길 색만 중립으로 바꿨습니다).
- 별 음성은 iPad에 내장된 한국어 음성(Safari speechSynthesis)을 씁니다. 인스타 릴스 같은 클라우드 AI 음성은 유료 TTS 서비스가 필요해서 넣지 못했습니다(Pollo 남은 크레딧 4개로는 대사 전체 약 2만 5천 자를 만들 수 없음). iPad 설정 › 손쉬운 사용 › 읽기 및 말하기 › 음성 › 한국어에서 '프리미엄'/'향상됨' 음성을 내려받으면 훨씬 자연스럽습니다. 첫 화면을 한 번 터치해야 소리와 음성이 켜집니다(iOS 정책). 무음 모드 스위치가 켜져 있으면 음악이 안 들릴 수 있습니다.
- three.js r160(ES 모듈 + 블룸 후처리)은 `cdn.jsdelivr.net`에서 받으므로 **처음 열 때 인터넷이 필요**합니다.
- 실제 iPad 기기에서의 프레임레이트는 아직 확인하지 못했습니다(헤드리스 브라우저에서만 테스트). 버벅이면 설정 → 그래픽 품질 → '가볍게'.
