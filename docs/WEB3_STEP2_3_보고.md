## 1. 이번에 실제 구현한 것
### STEP 2 — 조작감 (`web/src/core.js`, `TUNE.arcade` 모드에서만 적용, Unity 규칙 모드는 그대로)
| 항목 | 내용 |
|---|---|
| 좌우 관성 | 좌우 속도가 목표값을 지수 곡선으로 따라감(가속 7/s, 놓을 때 9/s, 반대로 꺾을 때 10/s). 순간이동처럼 꺾이던 느낌 제거 |
| 아날로그 조향 | 화면 왼쪽(아래 46%)을 손가락으로 좌우로 끌면 끈 거리만큼 조향(55 px = 최대). ◀ ▶ 버튼도 그대로 동작 |
| 드리프트 성공/실패 | 코너 방향으로 꺾을 때만 충전(직선에서는 충전 속도 25%). 1단계에 못 미치고 0.25초 넘게 끌었거나 드리프트 중 벽에 부딪히면 **실패: 속도 −12%**, 회색 불꽃, 실패 효과음. 성공은 단계별 효과음·색 불꽃·미니터보 |
| 점프 | 상승 중력 0.9배, 하강 1.55배 → 빠르게 뜨고 빠르게 내려옴(둥실거림 제거), 점프 속도 10.2 |
| 착지 | `Land` 이벤트 처리: 착지음, 몸 압축, 착지 먼지 |
| 회피 보상 | 지금까지 버려지던 `ObstacleDodged` 이벤트를 콤보로 연결(점프로 넘으면 "점프 회피" +100) |
| 카메라 | 흔들림 최대 0.4·감쇠 2배 빠르게(멀미 완화), 충돌 0.9→0.35, 부스트 시작 순간 FOV +6 펀치 |
| 성능 | 이온 입자: 매 프레임 240회 경로 계산 → 다시 생길 때만(프레임당 최대 6회). 오브: 매 프레임 전체 행렬 갱신 → 먹을 때 1개만. 별 꼬리 위치 객체 재사용 |

### STEP 3 — 그래픽·피드백 (`star.js`, 새 `fx.js`, `app.js`, `world.js`)
| 항목 | 내용 |
|---|---|
| STAR-01 | 부스트 시 별 끝이 뒤로 휘며 가장자리가 빛남(정점 셰이더), 충돌 시 하얗게 번쩍 + 찌그러졌다 회복, 정답 시 점프+회전, 오답 시 도리도리, 속도에 따라 앞으로 기울기, 좌우 기울기 부드럽게 |
| 그림자·착지 링 | 별 아래 그림자(높이에 따라 작아짐) + 공중에서 떨어질 때 착지 지점 링이 줄어들며 밝아짐 |
| 드리프트 자국 | 바닥에 두 줄 스키드 자국(단계 색: 파랑→주황→분홍) + 불꽃 입자 |
| 속도선 | 고속·부스트 때 화면 가장자리 속도선 |
| 코너 예고 | 급커브(반경 약 105 m 미만) 바깥 벽에 주황 ">>>" 화살표 |
| 콤보·점수 | 회피·점프 회피·드리프트 성공·연속 오브·결절 통과·정답·발화로 콤보 증가, 4초 무행동/충돌/벽/오답/드리프트 실패 시 끊김. 5콤보마다 배율 +0.5(최대 ×4). HUD 오른쪽에 콤보, 점수판(오브 → 점수), 결과 화면에 점수·최대 콤보, 스테이지별 최고 점수 저장 |
| 효과음 | 드리프트 지속음(단계별 높이), 부스트 굉음, 착지·점프·드리프트 성공/실패·발화·충돌·콤보음 분리, 같은 소리 겹침 방지 |
| 음량 | 배경음악/효과음 각각 끔·작게·보통·크게 (기존 켜기/끄기 저장값은 자동 변환) |

## 2. 유지한 것
문제은행·해설·도감·스토리 JSON, 저장 데이터(같은 키, 새 항목만 추가), 트랙·갈림길·게이트·보기 셔플, EPSP/IPSP 구간, 시냅스 미니게임, 9개 챕터, 보스 보호막, 음성 큐, 자동 화질 조정.
