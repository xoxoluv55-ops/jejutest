# ANATOMY ESCAPE — 설계 문서 (PHASE 1)

## 1. 기술 구조

| 영역 | 선택 | 이유 |
|---|---|---|
| 엔진 | **Phaser 3.90 (WebGL)** + TypeScript | 2D 스프라이트·파티클·물리·멀티터치가 내장되어 있고 iPad Safari에서 안정적 |
| 빌드 | Vite 6 | 빠른 개발 서버, 저장소 루트로 정적 빌드(GitHub Pages 바로 배포 가능) |
| 렌더링 해상도 | 논리 좌표(세로 900) × 기기 픽셀 밀도(최대 2배) | iPad Retina에서 선명함, 화면 비율에 따라 가로 폭 자동 확장 → 잘림 없음 |
| 사운드 | Web Audio API 절차적 합성 | 음원 파일 없이 앰비언트·경보·효과음·긴장 음악 생성, 첫 터치에 iOS 오디오 잠금 해제 |
| 저장 | localStorage | 설정, 도감 해금, 최고 기록 |
| 멀티플레이 | (PHASE 3) WebSocket 서버 | 정적 호스팅(GitHub Pages)만으로는 불가 → 별도 서버 필요 |

```
app/
  src/core      view(해상도·스케일), audio(사운드 합성), save
  src/art       bones(뼈 렌더러), env(연구시설 텍스처 페인터)
  src/data      anatomy(뼈 형상·지표·해설·도감), map(방·벽·조명 배치)
  src/game      Player(캐릭터 리그), Lighting(2D 조명), state(진행 상태·이벤트 버스)
  src/scenes    Boot / Title / Game / HUD / Info / Archive / Result
  src/scenes/puzzles  Assembly(골격 조립) / Align(관절면 정렬) / Xray(영상 판독)
  src/ui        커스텀 UI 키트(패널, 버튼, 아이콘)
tools/cutout.py 콘셉트 이미지 누끼 → 스프라이트 생성
```

## 2. 에셋 제작 방식

1. **캐릭터** — 콘셉트 이미지의 정면·측면·후면 실험체를 AI 배경 제거(rembg, isnet)로 누끼 → 3배 업스케일 → 그림자 헤일로 제거. 붉은 포인트 색만 색상 회전시켜 파랑·노랑·보라 변형 생성. 게임용(200px)과 타이틀용(원본) 두 크기.
2. **홀로그램 인체 모형** — 콘셉트 이미지의 캡슐 속 인체를 누끼 → 가산 혼합(ADD)으로 발광.
3. **뼈** — 해부학 좌표계(오른쪽 상지, 전면)에 타원·캡슐·다각형 기본형으로 각 뼈를 정의하고 캔버스로 렌더링. 같은 형상에서 **실물(아이보리)·X-ray(피질골 테두리)·홀로그램·점선 가이드** 4가지 스타일을 생성 → 퍼즐 판정과 그림이 항상 일치.
4. **연구시설** — 바닥·벽·소품 40여 종을 2배 밀도 캔버스로 페인팅(금속 판, 볼트, 스크래치, 오염, 화면 UI, 경고 줄무늬 등). 사용자가 생성한 이미지가 있으면 `public/assets/art/<key>.png`로 교체(크기 자동 맞춤).
5. **조명** — 카메라를 따라다니는 어둠 레이어에서 광원을 지워내는 방식 + 가산 색광. 정전 시 비상등과 플레이어 주변만 밝음.

## 3. 화면 구성

- **타이틀**: 로고(네온·글리치), 심전도 애니메이션, LOCKDOWN 경고판, 회전 경광등, 안개·먼지, 4색 실험체, 메뉴 4개(GAME START / MULTIPLAYER / ANATOMY ARCHIVE / SETTINGS).
- **브리핑**: 난이도(기초/심화)·실험체 색상 선택.
- **게임 HUD**: 좌상단 미션·잠금 3개 표시 / 우상단 미니맵(탭하면 전체 지도) + 일시정지 / 하단 중앙 표본 인벤토리 / 우하단 조작·SCAN·인벤토리·지도 버튼 / 좌하단 가상 조이스틱(손가락 위치에 생성, 끝까지 밀면 달리기) / 상단 AI 대사창 / 중앙 알림 / 화면 가장자리 목표 화살표.
- **퍼즐 터미널**: 전체 화면, 하단 피드백 줄, 성공 시 개념 정리 카드.
- **결과 화면**: 시간, 퍼즐별 오답·정확도, 학습 개념, 복습 추천.

## 4. 캐릭터 애니메이션 방식

방향별 고해상도 컷아웃 1장(정면/측면/후면) + **코드 기반 2D 리그**:

| 상태 | 표현 |
|---|---|
| Idle | 호버 상하 부유, 호흡 스케일, 미세 기울기 |
| Move | 가속·감속(지수 보간), 발걸음 바운스, 스쿼시&스트레치, 진행 방향 기울기, 방향 전환(정면/측면/후면 + 좌우 반전), 발밑 추진광 |
| Run | 더 큰 바운스·기울기, 잔상 파티클 |
| Interact | 대상 쪽으로 몸을 숙이는 찌그러짐 |
| Carry | 획득한 뼈 홀로그램이 머리 위에서 회전 |
| Scan | 떠오르며 회전 + 스캔 파동·조명 |
| Damage | 붉은 점멸, 넉백, 흔들림, 경직 |
| Victory | 점프·회전 + 파티클, 승강기 빔으로 상승 |

> 한계: 팔다리가 따로 움직이는 프레임 애니메이션은 아직 없음. 걷기 포즈 이미지(아래 ASSETS.md)를 받으면 프레임 애니메이션으로 교체 가능.
