# CH2 근육 연결실 — 방탈출 개편 (v0.10)

CH1과 같은 방식으로 바꿨습니다.
- **코어 얻는 방식:** 근육 데이터 코어는 바닥에서 손 버튼으로 줍지 않습니다. 각 코어는 **잠긴 장치** 안에 있고, 그 장치를 여는 **단서는 다른 물체**에 있습니다.
- **조사 화면:** 조사하는 동안 월드는 멈추고, 오답은 몇 번이든 다시 시도할 수 있습니다.
- **기초 / 심화 차이:** 기초는 단서에 위치·움직임 설명이 붙고 마지막 힌트가 답을 알려 줍니다. 심화는 이름만 나옵니다.
- **그대로 둔 흐름:** 근육 지도(LOCK 1) → 연결 콘솔(LOCK 2) → 과부하 방전 → 운동 재현(LOCK 3) → 게이트.

- **그림:**
  - 뼈 모형, 근육, 팔꿈치 각도 프레임은 모두 BodyParts3D 모델 렌더입니다.
  - 열쇠구멍·단추·케이블 고리 위치는 측정한 부착 위치(`data/muscles.ts`의 ATT, 모델 프레임의 근육 경로 끝점)입니다.
  - 열쇠, 열쇠구멍, 누름 버튼은 3D로 렌더링한 소품 레이어입니다.
- **저장:** 이어하기 시 회수한 코어와 단서가 유지되고, 장치는 남은 코어 기준으로 다시 열립니다.

## 검증 (헤드리스, 실제 터치·드래그; 실제 iPad 테스트는 하지 않음)
- **기초(1180×740):** 코어 4개 모두 오답 → 재시도 → 정답 → 회수 순서로 진행했습니다(오답 5회, 각각 이유 표시).
- **심화(1180×740):** 코어 6개 모두 회수했습니다(부리위팔근 열쇠, 위팔노근 90° 단계 포함).
- **아이폰 가로(852×330) 기초:** 네 퍼즐을 진행했습니다.
- **CH2 전체(기초·심화):** 코어 회수 → 연결 → 운동 재현 → 결과 화면까지 진행했습니다.

## 함께 고친 버그
- **운동 재현 퍼즐이 열리지 않던 문제:** 팔꿈치 모형(위팔세갈래근 장치)을 먼저 조작하면 `mo_elbow` 데이터가 이미 캐시에 있어, 운동 재현 퍼즐의 프레임 로딩 콜백이 등록되지 않았습니다. 그래서 퍼즐이 열리지 않았습니다. 이제 관절(팔꿈치·어깨)마다 캐시가 있으면 바로 프레임을 불러오고, 없으면 로딩이 끝난 뒤 불러옵니다.
