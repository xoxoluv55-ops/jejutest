# NERVE RUNNER 2.0 — PHASE 0. 기존 그래픽 구조 분석

> 대상: `claude/nerve-runner-racing-game-wkgzek` (커밋 `4f2f754`) · 작업 브랜치: `claude/nerve-runner-visual-upgrade`

## 1. 현재 구조 요약

| 영역 | 1.0 구현 | 평가 |
|---|---|---|
| STAR-01 메시 | `MeshKit.PuffyStar` — 극좌표 반지름 함수 + 돔형 두께의 절차 메시 (140×12) | ✅ 형태는 좋음 → **유지**. 외부 AI 모델로 바꿀 이유 없음 |
| STAR-01 재질 | URP/Lit 단색 + Emission | ⚠ 평면적. 명암·림라이트가 없어 실루엣이 약함 |
| 얼굴 | 구(sphere)를 늘려 눈·입 표현, 크기만 바꿔 표정 | ⚠ 기쁨/충돌/오답 구분이 어려움, 눈썹 없음 |
| 애니메이션 | 기울기(횡속도), 드리프트 요 28°, 점프 회전, 부유, 부스트 진동 | ✅ 사용자 확인 "자연스러움" → **값 그대로 보존** |
| 효과 | TrailRenderer 1개(불투명 Unlit) + 점광원 | ❌ 파티클·스파크·잔상 없음 |
| 트랙 | `TrackView`: 도로 리본 + 네온 레일 + 하부 섬유 + 표지판(월드 캔버스), 정적 배칭 | ✅ 유지 |
| 도약전도 터널 | 금색 토러스 고리를 6 m마다 + 결절 위치에 빈 간격 + 청록 링 | ⚠ 수초(감싼 막)·결절(노출된 축삭막, Na+ 통로)을 학습적으로 보여주지 못함 |
| 배경 | `NeuralBackdrop`: 뉴런 60개(구+원통 가지) + 바닥 스파크, 정적 배칭 | ⚠ 단순 (PHASE 2 대상) |
| 카메라 | Neon Racer 추적 카메라 각색: 거리 7.5, 높이 3.2, 속도 FOV, 흔들림 | ⚠ 별이 작게 보임, 코너/드리프트 시점 변화 없음, 흔들림 강도 조절 없음 |
| 조명 | 방향광 1개(보라) + 별 점광원 + 트라이라이트 앰비언트 + 선형 안개 | ⚠ 모바일 렌더러는 HDR OFF |
| URP 설정 | PC: Forward+ / HDR / 깊이 텍스처. Mobile: Forward / HDR OFF. 깊이 프라이밍 OFF | 블룸은 데스크톱 전용(Neon Racer의 모바일 흰 화면 대응) |
| 셰이더 | URP Lit/Unlit만 사용 (Always Included) | 투명 효과용 셰이더 없음 |
| UI | 코드 생성 UGUI, OS 한글 폰트 | PHASE 3 대상 |

## 2. 모바일(iPad) 성능 위험

| 위험 | 상태 |
|---|---|
| 런타임 머티리얼의 셰이더 변형 제거 | `Resources/VariantKeep_*.mat`로 대응 (1.0) |
| 오브젝트 수 | 배경·트랙 정적 배칭 |
| 파티클 | 1.0에는 없음 → 2.0에서 추가하므로 **품질 설정으로 상한 필요** |
| 포스트프로세싱 | 모바일 HDR OFF → 블룸은 데스크톱(High)만 |
| 실시간 그림자 | 사용 안 함 → 2.0에서 **블롭 그림자**(투명 쿼드)로 대체 |

## 3. 결론: PHASE 1 범위
- **유지:** 시뮬레이션(`RunnerSim`) 전체, 별 메시 수식, 1.0 모션 값, 트랙 생성, 학습 시스템.
- **개선:** 별 재질·얼굴·반응 애니메이션·이펙트·카메라 / 도약전도 터널 표현.
- 외부 AI 3D 모델은 불필요하다고 판단했습니다(아래 PHASE 1 보고서 §3 참고).
