# STEP 03 보고서 — HUD · VFX 품질 1차 개선

캐릭터 모델(VRoid)은 공주님 PC 작업 대기 중이라, 모델 없이 가능한 HUD·VFX·피격 반응부터 개선했습니다.

## Implemented

### HUD
- **캐릭터 초상화 수정**
  - 빨강/파랑 단색 박스가 나오던 문제를 고쳤습니다. 렌더 방식을 "몇 프레임에 걸쳐 전용 레이어 카메라로 촬영"으로 바꿨습니다.
  - 렌더가 끝나기 전에도 단색 대신 어두운 캐릭터 색이 보입니다.
  - 테두리는 P1 빨강 / P2 파랑 외곽선이고, 배경은 어두운 판입니다. 큰 컬러 박스는 없앴습니다.
  - P2 초상화는 좌우를 뒤집어 화면 중앙을 바라보게 했습니다.
  - 피격 시 초상화가 흔들리고 붉게 깜빡입니다.
- **체력바**
  - 현재 HP는 즉시 줄고, 지연 HP(빨간 바)가 0.55초 뒤에 따라옵니다.
  - 체력이 크게 깎이면(4% 이상) 바가 하얗게 번쩍이고 흔들립니다.
  - 체력 25% 이하에서는 테두리가 붉게 은은히 깜빡입니다.
- **스페셜 게이지**
  - 게이지가 부드럽게 차오르고, 차오르는 끝부분이 빛납니다.
  - 칸이 꽉 차면 펀치 애니메이션 + 사운드가 나옵니다.
  - MAX가 되면 강한 맥동과 빛이 납니다.
- **콤보 표시**
  - 히트 수가 늘수록 숫자가 커집니다.
  - 색상: 2~4히트 노랑 → 5~9히트 주황 → 10히트 이상 빨강·금색.
  - GOOD (3히트) / GREAT! (6히트) / AMAZING!! (10히트) 표시와 효과음이 나옵니다.
  - 숫자 뒤에 글로우가 깔립니다.

### VFX
| 상황 | 이펙트 |
|---|---|
| 약공격 | 작은 스파크 |
| 중간 공격 | 스파크 + 근섬유 |
| 강공격 / 얼티밋 | 큰 플래시 + 충격파 링 + 근섬유 폭발 + 파편 + 짧은 화면 팝 |
| 가드 | 파란 실드 링 + 플래시 (퍼펙트 가드는 금색 링 추가) |
| 카운터 히트 | 짧고 날카로운 화이트 플래시 + 짧은 줌 + 히트스톱 강화 |

- **공격 트레일 차별화**

| 공격 | 트레일 |
|---|---|
| 펀치 | 짧고 얇은 호 |
| 킥 / 런처 | 길고 넓은 호 |
| 강공격 | 넓은 트레일 |
| Muscle Skill 성공 | 근섬유 트레일 |

- **피격 반응**
  - 맞으면 머리가 젖혀지고 상체가 뒤로 꺾입니다.
  - 강공격·카운터에는 무릎이 꺾이는 휘청거림이 추가됩니다.

3. 게이지 MAX일 때 맥동하는지
4. 3 / 6 / 10 콤보에서 GOOD / GREAT / AMAZING이 나오는지
5. 약공격과 강공격, 펀치와 킥이 이펙트·트레일만 봐도 구분되는지
