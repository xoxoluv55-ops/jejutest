## P4 성장·아이템
- **진화 5단계**: Rookie → Spark(XP 2) → Pulse(5) → Nova(9) → Synapse Master(14). XP는 학습 성취로만: 정답률 80% 이상 클리어 +1, 만점 +1, 라이벌 1위 +1, 서바이벌 60초 이상 +1. 진화 시 결과 화면·음성 알림, 몸 색·꼬리·후광 색이 바뀜. 타이틀 › ⭐ STAR-01 진화·스킨에서 해금된 모습 선택.
- **신경전달물질 아이템**(아이템 상자 🧪 → 오른쪽 아래 [아이템] 버튼, 키보드 E):
  - 🟢 글루탐산: 막전위 +12 mV · 가속 (흥분성 시냅스 비유)
  - 🔵 GABA: 4초 보호막(충돌 1회 무효) · 막전위 −12 mV (억제·안정화 비유)
  - 🟡 아세틸콜린: 슈퍼 점프 (신경근접합부 → 근육 수축 비유)
  - 🟣 도파민: 6초간 점수 ×2 (보상 학습 비유)
  - 화면 문구에 "교육적 비유 — 실제 작용은 수용체·회로에 따라 다름" 명시.

## NULL 보스 3페이즈 (CH.9)
| 페이즈 | 내용 |
|---|---|
| 1 신호 교란 | 레이저·움직이는 블록 패턴, 에너지 오브·아이템 확보 |
| 2 진단 | 진단 게이트 5개. **정답이어도 체력은 안 깎임** — 약점(노란 링)이 열리고, 그 링을 직접 통과해야 1 대미지. 오답이면 약점이 닫힌 채 반격 |
| 3 최종 패턴 | 결절 링 8개·빠른 레이저·움직이는 블록·점프대 → 최종 진단 갈림길 → NULL 코어(부스트/미니터보 상태로 통과 시 3 대미지, 아니면 1) |
- 체력 8(약점 5 + 코어 3). 페이즈 시작마다 큰 배너·음성·보스 쪽으로 카메라가 잠깐 돌아감. 0이면 "NULL 소멸! 신경망 복구 완료", 아니면 "NULL 도주(남은 체력)".
- 검증: 전부 오답으로 달리면 체력 8/8 그대로(정답만으로 자동 격파되지 않음), 정답+약점 통과 시 0/8.
