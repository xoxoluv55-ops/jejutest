# 지원 화면과 레이아웃 (v0.4)

게임 좌표는 "논리 단위"를 씁니다(`app/src/core/view.ts`).
- 논리 높이는 화면 CSS 높이를 따르며 최대 900입니다.
- 논리 너비는 1180보다 작아지지 않습니다. 화면이 더 좁으면 너비를 1180에 맞추고, 그만큼 전체를 축소해 그립니다.

| 기기 (가로) | 게임 영역 CSS | 논리 크기 | 화면 배율 | 레이아웃 |
|---|---|---|---|---|
| iPad Air/Pro 11" Safari | 약 1180×740 | 1180×740 | 1.0 | 일반 |
| iPhone 15/16 Pro Safari (탭 막대 표시) | 약 852×330 | 1180×457 | 0.72 | **압축(compact)** |
| iPhone 홈 화면에 추가(전체 화면) | 약 734×372 (노치 여백 제외) | 1180×598 | 0.62 | 압축 |

## 압축 레이아웃 (논리 높이 640 미만)
- **공통**
  - 퍼즐 머리글을 한 줄로 줄입니다(제목 + 안내문 최대 2줄 + 닫기 버튼).
  - 아래 안내 막대를 48px로 줄이고, 긴 문장은 글자를 줄여 막대 안에 넣습니다.
  - 여백을 6px로 줄입니다.
- **뼈대 조립**
  - 목표 상자를 두 줄로 줄이고, 카드 이름을 한 줄("자뼈 Ulna")로 표시합니다.
  - 카드와 폐기함의 높이를 줄입니다.
  - 오른쪽 안내 칸(60px)은 카드를 가리지 않습니다.
- **관절 정렬**
  - 팔뼈대 부분만 잘라 크게 보여 줍니다. 이 변경은 iPad에도 적용됩니다.
  - 회전·반전 버튼을 한 줄에 나란히 놓습니다.
- **X-ray, 근육 지도**
  - 이름표의 행 간격과 높이를 줄입니다.
  - 근육 지도의 출처 표기는 그림 모서리로 옮깁니다.
  - 단서 문장이 칸을 넘으면 넘치는 줄을 잘라 냅니다. 같은 단서는 오답 안내에도 나옵니다.
- **이는곳·닿는곳 연결**
  - 부착 지점이 있는 부분만 잘라 보여 줍니다.
  - 지점 이름을 그림 왼쪽에 한 줄씩 겹치지 않게 늘어놓고, 각 이름에서 지점까지 선을 긋습니다.
  - 근육 목록은 2열로 표시합니다.
- **운동 재현**
  - 근육 역할 버튼을 근육 이름과 같은 줄에 놓습니다.
  - 역할 검증이 끝나면, 근육 길이 변화 표가 역할 버튼 자리에 나타납니다. 그림이 작아 그림 위에 두지 않습니다.
  - 단순화 안내 문구는 그대로 둡니다. 화면 아래 작용선 설명은 12px 작은 글씨로 표시합니다.
- **탐색 화면 HUD**
  - 미니맵과 조작 버튼을 작게 줄입니다.
  - 미션 창은 진행 중인 미션 한 줄만 보여 주고, 누르면 펼쳐집니다.
  - 인벤토리 칸을 46px로 줄입니다.
- **타이틀, 미션 브리핑, 결과, 설정, 도감, 협동 안내**
  - 세로 간격을 줄입니다.
  - 결과 보고서는 2열(기록 | 학습 개념·복습 추천)로 표시합니다.

## 글자 크기
- 기본 하한은 논리 15px입니다. 출처 표기 같은 작은 글씨는 12px입니다.
- iPhone(배율 0.72)에서는 본문 15px이 실제 약 11px, 작은 글씨는 약 9px로 보입니다.
- iPad보다 작습니다. 화면 높이가 330px뿐이라 더 키우면 퍼즐이 한 화면에 들어가지 않습니다.
- 화면을 넓히는 방법:
  - Safari의 "가로 탭 막대"를 끕니다(설정 › 앱 › Safari).
  - 또는 공유 › "홈 화면에 추가"로 전체 화면 실행합니다.

## 검증 범위
- 헤드리스 Chromium에서 852×330(iPhone 가로 + Safari 탭 막대)과 1180×740(iPad 가로)으로 확인했습니다.
  - 모든 화면을 캡처했습니다.
  - CH1·CH2 기초·심화 전체 플레이 자동 테스트를 돌렸습니다.
- **실제 iPhone·iPad에서는 확인하지 않았습니다.**
- 확인하지 않은 항목:
  - 실제 손가락 조작감과 작은 버튼의 터치 정확도
  - Safari 툴바가 보이고 숨을 때의 크기 변화
  - 노치·홈 인디케이터 안전 영역
