# CH3 손목·관절실 — 방탈출 (v0.11)

CH1·CH2와 같은 방식입니다.
- **표본 얻는 방식:** 손목뼈 8개가 장치 4개에 두 개씩 잠겨 있고, 각 장치를 여는 단서는 다른 물건에 있습니다.
- **조사 화면:** 조사하는 동안 월드는 멈추고, 오답은 몇 번이든 다시 시도할 수 있습니다.
- **기초 / 심화 차이:** 기초는 단서에 이름·위치 설명이 붙고 마지막 힌트가 답을 알려 줍니다. 심화는 설명을 줄이고 함정(발의 뼈)과 단계를 더합니다.

## 흐름
손 X선 판독(LOCK 1, J-02) → 손목뼈 8개 회수(장치 4개) → 손목뼈 재조립(LOCK 2, J-01) → 관절 시험 프레스 과압(75초 안에 J-04 감압 밸브) → 관절 시험실 개방 → 관절 유형 판정(LOCK 3, J-03) → 게이트 → 승강기.

맵은 CH2 연구동을 좌우로 뒤집어 썼습니다. 벽과 문 규칙은 같고, 방 이름·조명·벽 색은 새로 정했습니다.

## 잠금 퍼즐
- **LOCK 1 손 X선 판독:** 3D 모델로 계산한 모의 PA 영상에서 요청한 손목뼈를 누릅니다. 맞히면 윤곽이 나타납니다.
  - 기초: 5개.
  - 심화: 8개. 마지막은 증례 문제입니다(해부학코담배갑 압통 → 손배뼈).
  - 영상에는 "모의 방사선 영상 · 3D 뼈 모델로 계산 · 실제 환자 영상 아님"이라고 표시됩니다.
- **LOCK 2 손목뼈 재조립:** 손목뼈 8개를 빈 손목(노뼈·자뼈·손허리뼈) 제자리에 끼웁니다.
  - 기초: 반투명 그림자와 줄 이름이 보입니다.
  - 심화: 그림자가 없고, 발목뼈(발배뼈·입방뼈) 함정이 섞입니다.
- **LOCK 3 관절 유형 판정:** 팔(CH1 모델)과 손(CH3 모델)의 번호 붙은 관절에 유형 칩을 놓습니다. 맞히면 운동축과 설명이 나옵니다.
  - 기초 6개: 어깨=절구, 위팔자=경첩, 몸쪽 노자=중쇠, 노손목=타원, 엄지 손목손허리=안장, 손목뼈사이=평면.
  - 심화는 2개를 더해 8개: 검지 MCP=타원, PIP=경첩.

## 그림
- 모든 손 그림은 BodyParts3D 4.0(© DBCLS, CC BY 4.0) 메시를 렌더한 것입니다(`tools/anatomy3d/ch3_hand.py`).
  - 시점: 오른손 손바닥 쪽, 손가락이 위, 엄지가 오른쪽.
  - 손 좌표계는 메시에서 측정했습니다: 손목뼈 중심 → 손허리뼈 머리 방향, 손목뼈·손허리뼈 평면, 콩알뼈 쪽이 손바닥.
- 핀 자리, 받침, 고리 위치는 모두 메시에서 측정했습니다.
  - 뼈 중심, 접촉면(노뼈–손배뼈 등), 손허리뼈 바닥과 손목뼈의 접촉, 굽힘근지지띠와 뼈의 접촉, 가장 손바닥 쪽 점(갈고리, 결절).
  - 연골은 모델에 없어서, 관절 접촉은 "최소 거리 + 1.5 mm"로 잡았습니다.
- 손 X선은 `tools/anatomy3d/ch3_xray.py`로 계산했습니다. CH1 어깨 X선과 같은 방법입니다.
- 도감에 손목뼈 8개와 개념 3개(손목뼈 배열, 손 PA 영상, 윤활관절의 종류), 기록 2개를 추가했습니다.

### 이번에 찾아서 고친 문제
- 결과 화면: 3장을 깼는데 "CHAPTER 2 ▶" 버튼이 나왔습니다. 이제 다음 장 번호로 나오고, 3장에서는 버튼이 없습니다.
- 관절면 금고: 노뼈·자뼈 그림이 상자 밖으로 삐져나왔습니다 → 상자 안으로 잘라 냈습니다.
- 손목굴 고정기: 콩알뼈가 세모뼈 손바닥 면에 얹혀 있어 두 핀 자리가 겹쳤습니다 → 세모뼈 후보를 빼고, 가장 가까운 핀 자리를 고르게 했습니다.
- 손가락 축 정렬기: 배경(손목뼈 + 노뼈·자뼈) 그림이 로딩 목록에서 빠져 있었습니다 → 추가했습니다.
- 관절 판정: 팔 그림이 작고 팔꿈치 표시 2개가 겹쳤습니다 → 팔 부분을 확대하고, 표시를 관절에서 조금 떨어뜨려 지시선으로 이었습니다.
