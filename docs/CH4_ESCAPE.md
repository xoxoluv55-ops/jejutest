# CH4 엉덩이·넙다리 근육실 — 방탈출 (v0.12)

CH1~CH3과 같은 방탈출 방식입니다.
- **코어 얻는 방식:** 근육 코어 8개가 잠긴 장치 4개에 두 개씩 들어 있고, 각 장치를 여는 단서는 다른 방의 물건에 있습니다.
- **조사 화면:** 조사하는 동안 월드는 멈추고, 오답은 몇 번이든 다시 시도할 수 있습니다.
- **기초와 심화의 차이:** 기초는 단서와 화면에 위치·이유 설명이 붙고, 마지막 힌트가 답을 알려 줍니다. 심화는 설명을 줄이고 함정과 단계를 더합니다.

## 흐름
1. 넙다리 단면 판독 (LOCK 1, H-01)
2. 장치 4개에서 근육 코어 8개 회수
3. 근육 재배치 (LOCK 2, H-01)
4. 하중 시험 트레드밀 과부하: 75초 안에 H-04의 비상 정지 스위치를 누름. 과부하 동안 바닥 배선에서 스파크가 튐
5. 보행 시험실 개방
6. 보행 재현 (LOCK 3, H-03)
7. 게이트 → 승강기

## 맵
`data/map4.ts`는 새로 만든 평면입니다. CH3처럼 CH2를 뒤집어 쓰지 않았습니다.

| 방 | 위치와 연결 |
|---|---|
| H-01 하지 근육실 | 중앙 허브 |
| H-02 볼기 해부실 | 서쪽 |
| H-03 보행 시험실 | 동쪽. 트레드밀을 정지하기 전까지 봉인 |
| H-04 하중 제어실 | 남서쪽. 허브와 연결 |
| H-05 표본 냉장실 | 남동쪽. 허브와 연결 |

H-04와 H-05는 서로 문으로 이어져 있어 남쪽이 한 바퀴 도는 구조입니다. 벽은 모래색, 조명은 주황 계열입니다.

## 잠금 퍼즐
- **LOCK 1 넙다리 단면 판독**
  - 3D 모델을 높이 590 mm(넙다리 중간)에서 수평으로 잘라 계산한 단면입니다.
  - 아래에서 본 방향(앞 = 위, 가쪽 = 왼쪽)이라 CT와 같은 방향입니다.
  - 요청한 근육을 단면에서 누릅니다. 기초는 5개, 심화는 8개이고 심화의 마지막은 증례(질주 중 뒤넙다리근 손상 → 넙다리두갈래근 긴갈래)입니다.
  - 다 맞히면 근육마다 칸 색(앞·안쪽·뒤)이 표시됩니다.
  - 화면에 "모의 단면, 피부·지방·혈관·신경 생략, 실제 환자 영상 아님"을 표시합니다.
- **LOCK 2 근육 재배치**
  - 앞면 골격판과 뒷면 골격판(나머지 근육은 어둡게 처리)에 회수한 근육 8개를 놓습니다.
  - 근육은 실제 위치로 붙고, 깊은 근육이 아래에 깔리도록 겹침 순서를 고정했습니다.
  - 심화는 그림자가 없고, 팔 근육(위팔두갈래근·어깨세모근) 함정이 섞입니다.
- **LOCK 3 보행 재현**
  - 움직임마다 근육별로 주작용근 / 대항근 / 관여 안 함을 정한 뒤 재현합니다.
  - 재현하면 리그가 움직이고, 짧아지는 케이블은 빨강, 늘어나는 케이블은 파랑 점선으로 그려집니다.
  - 움직임은 무릎 폄, 엉덩관절 폄, 엉덩관절 벌림(앞에서 본 리그) 세 가지입니다.

## 그림과 정확도
- 모든 그림은 BodyParts3D 4.0(© DBCLS, CC BY 4.0)의 오른쪽 골반·다리 메시를 렌더한 것입니다(`tools/anatomy3d/ch4_model.py`, `ch4_art.py`, `ch4_section.py`).
  - CH2와 같은 근육결(LIC) 후처리를 했습니다.
  - 렌더한 근육은 27개, 뼈는 볼기뼈·엉치뼈·허리뼈·넙다리뼈·무릎뼈·정강뼈·종아리뼈입니다.
- **측정값:** 부착점·표지 위치는 근육 메시와 뼈 표면의 접촉에서 측정했습니다(작은돌기, 큰돌기, 볼기근거친면, 궁둥뼈결절, 위·아래앞엉덩뼈가시, 종아리뼈머리, 거위발 등).
  - 엉덩관절 중심: 넙다리뼈머리 구 맞춤(r = 23.2 mm)
  - 무릎 중심: 두 관절융기 뒤쪽 면의 구 맞춤 중점(r ≈ 20 mm)
- **리그:**
  - 뼈를 강체로 돌립니다. 가쪽에서 본 리그에서 굽힘·폄은 화면 평면 안의 회전입니다.
  - 케이블은 모델에서 잰 경로(이는곳 → 경유점 → 닿는곳)이며, 각 점은 자기 뼈와 함께 움직입니다.
- **작용 검증:** `ch4_art.py`가 작은 회전에 대한 케이블 길이 변화를 계산해, 게임에서 쓰는 작용이 교과서와 맞는지 확인합니다.
  - 엉덩허리근·넙다리곧은근·큰볼기근·넙다리두갈래근·반힘줄근·가쪽넓은근·중간볼기근·긴모음근·두덩정강근(모음)은 모두 일치했습니다.
  - **넙다리빗근과 두덩정강근의 무릎 굽힘은 이 방법으로 재현되지 않았습니다.** 무릎을 편 자세에서 두 힘줄이 굽힘축 바로 앞을 지나기 때문입니다.
  - 그래서 운동 시험대와 보행 재현에서는 이 두 근육의 무릎 작용을 묻지 않고, 설명 글에만 교과서 내용을 적었습니다.
- **거위발 핀:** 세 힘줄의 실제 부착점은 서로 약 12 mm 안에 겹쳐 있어, 핀은 순서를 보여 주는 표시로 펼쳐 놓았습니다. 힘줄을 걸면 실제 위치로 붙습니다.
- **단면:** 메시끼리 약간 겹치는 곳은 작은 구조가 우선하도록 했습니다(넙다리두갈래근 짧은갈래가 긴갈래 안에 묻히지 않게). 넙다리뼈 속질은 모델에 없어 5 mm 겉질 띠로 양식화했습니다.

### 테스트 중 고친 문제
- **단면:** 넙다리두갈래근 짧은갈래가 긴갈래 영역에 덮여 사라졌고, 그 이름표가 화면 구석에 떴습니다 → 작은 구조가 우선하도록 바꿨습니다.
- **운동 시험대·보행 리그:** 무릎을 굽힌 다리가 상자 밖으로 나갔습니다 → 리그 영역을 넓히고 상자 안으로 잘라 냈습니다. 골반이 넙다리뼈머리를 덮는 순서도 바로잡았습니다.
- **거위발 고정핀:** 핀이 상자 아래 경계에 걸렸습니다 → 부착점 바로 위에 한 줄로 놓고 지시선으로 이었습니다.
- **신경 냉장고:** 서랍 이름표가 금속 배경에서 잘 안 보였습니다 → 어두운 바탕을 깔았습니다.
