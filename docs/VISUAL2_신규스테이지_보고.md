## 1. 새로 플레이할 수 있는 스테이지

### CH.7 대뇌 도시 (콘셉트 ⑥)
| 구역 (도로·건물 색) | 랜드마크 | 학습 |
|---|---|---|
| 이마엽 (주황) | 계획 타워, 지휘 돔 | 일차운동겉질(중심앞이랑), 브로카 영역·표현실어증 |
| 마루엽 (청록) | 감각 수신 접시 | 일차몸감각겉질(중심뒤이랑), 반쪽무시(오른쪽 마루엽) |
| 관자엽 (보라) | 음파 막대, 기억 보관소 돔 | 일차청각겉질(가로관자이랑), 베르니케 영역·수용실어증, 해마·기억 |
| 뒤통수엽 (파랑) | 거대 렌즈·스크린 | 일차시각겉질(새발톱고랑) |

- 코스는 이마엽 → 마루엽 → 관자엽 → 뒤통수엽 순서로 지나갑니다.
- **갈림길에서 정답을 고르면 그 정보를 처리하는 다음 엽으로 들어갑니다.** 예: "촉각 정보는?" → 마루엽 차선.
- 도로 아래에는 보라색 대뇌이랑 능선이 깔려 있습니다.
- 갈림길 3개와 게이트 5개, 문제 8개. 최단 경로 5,570 m, 자동 플레이 138초.

### CH.9 NULL 보스 아레나 (콘셉트 ⑦)
- 오류 개체 NULL 주위를 나선 트랙으로 약 3바퀴 돕니다. NULL은 사람 모양이 아니라 깨진 회로 조각, 붉은 심장박동 코어, 육각 보호막, 회전 신경 회로 링으로 이루어져 있습니다.
- **임상 진단 게이트 5개:** 증상을 보고 병변 위치가 맞는 차선으로 들어가면 NULL 보호막이 깨집니다.
  - 반대쪽 편마비 → 대뇌 (피라미드 교차)
  - 왼쪽 동측반맹 → 오른쪽 뒤통수엽
  - 같은 쪽 겨냥이상 → 같은 쪽 소뇌
  - 반사 소실·근위축 → 아래운동신경세포
  - 유창하지만 이해 못하는 실어증 → 베르니케 영역
- **NULL 반격:** 전폭 파동은 점프로, 글리치 블록은 피해서 넘깁니다. 오답이면 파동 공격이 나갑니다.
- **최종 진단 갈림길:** 브라운-세카르 증후군을 맞히면 탈출 지름길이 열립니다.
- HUD에 **NULL 보호막 바**가 표시되고, 결과 화면에 "NULL 격파!" 또는 "NULL 도주... 재도전!"이 나옵니다.
- 문제 6개(Master 난이도). 자동 플레이 91초 + 읽기·연출 시간.

### 스테이지 선택·도감
- 스테이지 선택 화면에서 CH.1·CH.7·CH.9 카드가 열립니다(색 강조, 기록·별 표시). 나머지는 "잠김".
- 신경 도감에 챕터 탭(CH.1/7/9)을 추가했습니다. 항목 수: 15 + 11 + 5 = 31.
- 타이틀의 "게임 시작"은 마지막으로 플레이한 스테이지로 이어집니다.

## 3. 학습 정확성 메모
- **대뇌엽 기능:** 대표 기능 위주로 단순화했습니다. 언어 영역은 "대부분 왼쪽(우세 반구)"이라고 명시했습니다.
- **진단 문제:** 표준 신경해부학 원칙에 근거합니다. 교차 위치(피라미드 교차, 척수 내 앞가쪽계 교차), 시각 경로 반맹, 소뇌의 같은 쪽 증상, 위·아래운동신경세포 징후.
- **AI 콘셉트 이미지는 따르지 않은 부분이 있습니다.** 해부 구조가 부정확할 수 있어 게임은 문제 데이터와 해설을 기준으로 구현했습니다.
