# CH1 팔뼈대 조립 퍼즐 — 학습 목표와 구성 (v4, iPad 가로 개편)

## 학습 목표
**오른쪽 팔뼈대(앞면)에서 팔이음뼈와 자유팔뼈를 제자리에 놓을 수 있다.**

| 구분 | 이 퍼즐의 뼈 | 설명 |
|---|---|---|
| 팔이음뼈 (pectoral girdle) | 빗장뼈 Clavicle · 어깨뼈 Scapula | 몸통과 팔을 잇는 뼈. 몸통 뼈대와는 복장빗장관절 하나로만 연결된다 |
| 자유팔뼈 (free upper limb) | 위팔뼈 Humerus · 노뼈 Radius · 자뼈 Ulna | 팔이음뼈에 매달려 움직이는 뼈. **손뼈(손목뼈·손허리뼈·손가락뼈)도 자유팔뼈이지만 이번 조립에서는 제외**하며 화면에 그렇게 표시한다 |

- 이전 판의 "팔 뼈대 재조립"은 대상 범위를 밝히지 않았다. 이번 판은 목표 상자에 위 정의를 항상 보여 준다.
- 그림과 윤곽 색도 이 구분을 따른다: 노란색은 팔이음뼈, 파란색은 자유팔뼈.
- 이름은 신용어를 먼저 쓰고 영어를 함께 적는다 (예: 빗장뼈 / Clavicle).

## 방해 선택지 (종아리뼈 Fibula)
- 종아리뼈는 **의도된 방해 표본**이다. 다리의 긴뼈라 노뼈·자뼈와 모양이 비슷하지만 팔꿉관절을 이루지 않는다.
- **기초**: 종아리뼈를 맵에 배치하지 않는다. 회수 표본은 5개이고 조립은 5/5로 끝나며 폐기함도 없다. 기초 학습자에게는 혼란만 주는 선택지이므로 제거했다.
- **심화**: 이름을 가린 표본 6개 가운데 다리뼈 1개가 섞여 있고, 목표 상자에도 그렇게 알린다. 학습자는 비슷한 긴뼈(노뼈·자뼈·종아리뼈)를 몸쪽 끝 모양으로 구별해 폐기해야 한다. 이것이 의미 있는 변별이다.

## 조작 (터치 기준)
- 카드 전체가 터치 영역이다. 1180×740 화면에서 한 장은 약 250×130 px(심화)~250×170 px(기초)이다.
- 놓는 방법은 두 가지다.
  - **끌어 놓기**: 끄는 동안 뼈가 손가락보다 46 px 위에 떠서 손가락에 가리지 않는다. 손가락 아래에 있는 자리는 흰 테두리로 강조된다.
  - **탭-탭**: 카드를 누르면 노란 테두리로 선택된다. 그다음 그림에서 놓을 자리를 누른다.
- 긴뼈(위팔뼈·노뼈·자뼈·종아리뼈)는 카드 안에서 가로로 눕혀 크게 보여 준다. 집어 들면 해부학적 자세로 선다.
- 정답 표시:
  - 제자리에 붙고 빛난다.
  - 그림 위에 `✓ 이름 English` 이름표가 붙는다.
  - 카드는 초록색 "배치 완료"로 바뀐다.
- 오답 표시: 카드가 빨갛게 바뀌고 흔들리며, 화면이 약하게 흔들린다. 오른쪽 아래의 **전용 피드백 상자**에 큰 글씨로 이유를 보여 준다.
- 피드백 상자는 카드·안내문과 겹치지 않는 고정 영역이다. 문장이 길면 글자를 18 → 15 px까지 줄여 상자 안에 넣는다.

## 진행 표시
- 기초: `조립 n/5`
- 심화: `조립 n/5 · 폐기 n/1`
- 완료하면 기존과 같이 개념 카드 `c_girdle`이 나오고 통계(`stats.assembly`)가 기록된다.

## 검증 범위
- 헤드리스 Chromium에서 1180×740 CSS px로 확인했다. 이 크기는 iPad Air 가로 화면에서 Safari 주소창이 보이는 경우를 가정한 값이다.
  - 터치 이벤트(탭·드래그)로 기초·심화 조립을 끝까지 진행했다.
  - CH1·CH2 전체 플레이 자동 테스트를 돌렸다.
- **실제 iPad에서는 확인하지 않았다.** 확인하지 않은 항목:
  - 손가락 크기에 따른 실제 조작감
  - Safari 툴바가 보이고 숨을 때의 레이아웃 변화
  - 홈 인디케이터 영역(`env(safe-area-inset-*)`)이 실제로 적용되는지
