# NERVE RUNNER v4.0 — P2 보고 (AI 라이벌 · 타임어택 · 서바이벌)

## 1. 기존 코드 분석
- 판정/진행 상태가 트랙 이벤트 객체 자체(`e.consumed`)에 저장돼 있어서, 같은 트랙에 레이서를 여러 명 올리면 한 명이 먹은 오브·게이트를 다른 레이서도 '이미 처리됨'으로 보게 되는 구조였음.
- 순위 계산에 쓸 "코스 진행도"가 없었음(갈림길 가지마다 길이가 달라 단순 거리로는 비교 불가).

## 2. 변경 (core.js)
| 항목 | 내용 |
|---|---|
| 레이서별 이벤트 기록 | `new Sim(graph, { own: true })` → 레이서마다 따로 기록(Set). 플레이어는 기존 방식 그대로 |
| 코스 진행도 | 세그먼트마다 `prog0`·`progScale` 계산. 갈림길의 모든 가지가 같은 속도로 진행도를 쌓아 공정한 순위 비교 |
| 속도 배율 | `sim.speedScale` (라이벌 고무줄 보정, 서바이벌 가속) |
| AI 성격 | `AutoPilot({ accuracy, noise, drift, boostAt })` — 정답률, 조향 흔들림, 드리프트 사용 여부, 부스트 성향 |
| 서바이벌 코스 | 세트 피스 26개를 무작위로 이어 붙인 약 12–13 km 코스(문제 없음) |

## 3. 모드 (app.js) — 스테이지 선택 화면 위쪽 탭
| 모드 | 규칙 |
|---|---|
| 📖 스토리 | 기존 그대로(대화·음성 해설·생각 시간) |
| 🏁 라이벌 레이스 | GLUTA(공격형: 최고속 41.5, 정답률 70%, 부스트 남발, 조향 거침) · GABA(안정형: 39.2, 88%, 드리프트 안 함, 부스트 아낌) · AXON(균형형: 40.6, 80%). 셋 다 **자기 시뮬레이션으로 실제 트랙을 주행**(갈림길 선택·장애물·점프 포함). 화면 왼쪽 위 실시간 순위표(앞/뒤 거리), 나란히 붙으면 몸싸움(옆으로 밀림), 앞서가면 아주 약간 느려지고 뒤처지면 약간 빨라지는 보정(±6%). 결과: 최종 순위·각자 기록, 스테이지별 최고 순위 저장. 대화 없음, 해설은 짧게 2.5초 |
| ⏱ 타임어택 | 25/50/75% 지점 구간 기록 + 최고 기록 대비 ±초 표시, 최고 기록을 세우면 그 주행을 0.1초 간격으로 저장해 **다음 도전부터 반투명 고스트**로 함께 달림. 슬로모션·음성 해설·대화 없음 |
| ∞ 서바이벌 | 진행할수록 속도 ×1.0→×1.4, 신호 에너지가 시간이 갈수록 빨리 닳음(충돌 −25%), 오브로 회복, 에너지 0이면 종료. 최고 생존 시간·점수 저장 |
저장 데이터: 기존 키에 `mode`, `rivalBest`, `ta`(기록·구간·고스트), `survival`만 추가 — 기존 기록·오답 노트·도감은 그대로.

## 4. 테스트 (이 환경에서 가능한 범위)
- Node: 라이벌 3명이 플레이어와 같은 트랙에서 완주(CH.1: AXON 223.0 · 플레이어 225.9 · GLUTA 226.7 · GABA 238.2초), 플레이어 오브 수 영향 없음(이벤트 공유 문제 없음), 9개 스테이지 기존 규칙 테스트 통과.
- 헤드리스 브라우저 자동 주행: 결과는 아래 실행 로그 참고(라이벌·타임어택 2회·서바이벌).
- **실기기(iPad/iPhone) 테스트·FPS 측정 못 함.** 라이벌 3명이 추가되면 프레임마다 물리 계산이 늘어나므로, 끊기면 설정 › 성능 표시로 확인 부탁.
