# NERVE RUNNER 2.1 — 전체 9개 코스 오픈 + 렉(성능) 개선

> 브랜치 `claude/nerve-runner-visual-upgrade`. Unity·iPad 실행은 이 환경에서 확인하지 못했습니다(아래 확인 요청 참고).

## 1. 렉 개선
원인으로 확인한 코드와 수정 내용입니다.

| 원인 (코드에서 확인) | 수정 |
|---|---|
| HUD 글자 5개(시간·속도·코인·정답·드리프트)를 **매 프레임** 새 문자열로 갱신 → HUD 캔버스 전체 재구성 + 메모리 할당(GC 끊김) | 값이 바뀔 때만 갱신, 시계는 0.1초 단위, 속도는 2 km/h 단위 |
| 토스트 글자 페이드를 색상 변경으로 처리 → 매 프레임 메시 재구성 | CanvasGroup 알파로 변경 + 별도 캔버스 |
| 자주 바뀌는 HUD 패널이 HUD 전체와 한 캔버스 | 타이머·코인·에너지·진행바·보스바를 각자의 하위 캔버스로 분리 |
| 결절 링 깜빡임 처리에서 매 프레임 `new List` + `Transform.name` 문자열 할당 | 재사용 리스트, 이름 비교 제거 |
| 별 표정 오브젝트 `SetActive`·눈썹 메시를 매 프레임 재지정 | 상태가 바뀔 때만 변경 |
| 배경 뉴런·대뇌 도시 건물이 아주 멀리서도 그려짐 | 거리 컬링(소품 레이어): 낮음 180 m / 중간 280 m / 높음 420 m |
| PC 기본값이 "높음"(SMAA + 블룸) | VRAM 4 GB 이상 PC만 "높음", 나머지는 "중간"(FXAA, 블룸 없음) |
| 배경 뉴런 60개 고정 | 낮음 18 / 중간 36 / 높음 60 |
| 별의 점광원 | 낮음에서는 끔 |

- **FPS 표시:** 설정 → **성능 표시(FPS)**를 켜면 화면 왼쪽 위에 FPS, 0.5초 구간의 최대 프레임 시간(ms), 품질 단계가 나옵니다. 렉이 남아 있으면 이 숫자를 알려 주세요.

## 2. 전체 코스 오픈 (CH.1~9 모두 플레이 가능)
| 챕터 | 코스 | 주요 학습 | 문제 |
|---|---|---|---|
| CH.2 | 척수 반사 회로 (초록) | 앞뿔/뒤뿔, 뒤뿌리신경절, 근육방추, 단일시냅스 반사, 반사궁 순서, 상호억제, 굽힘·교차폄반사 | 7 |
| CH.3 | 신경로 고속도로 (분홍) | 뒤기둥-안쪽섬유띠계·앞가쪽계·척수소뇌로, 교차 위치, 겉질척수로·피라미드 교차, 안뜰척수로 | 7 |
| CH.4 | 뇌줄기 터널 (주황) | 흑색질, 위·아래둔덕, 중뇌수도관, III·IV 신경핵, 다리뇌-중간소뇌다리, 숨뇌 생명 중추 | 7 |
| CH.5 | 소뇌 균형 서킷 (분홍빛, 급커브 2개) | 소뇌 기능, 조롱박세포, 소뇌다리, 벌레 손상, 의도떨림 | 6 |
| CH.6 | 사이뇌 중계 기지 (청보라) | 시상 중계(VPL·가쪽무릎체), 시상하부 항상성, 뇌하수체, 솔방울샘 | 6 |
| CH.8 | 12뇌신경 포털 (금색) | 감각/운동/혼합 분류, LR6 SO4, 얼굴·삼차신경, 혀밑신경 치우침, 미주·더부신경 | 8 |

- **코스 구성:** 공통 모듈 빌더(`QuizCourseLayout`)에 단계 목록을 넣어 만듭니다. 진입로, 게이트, 갈림길(정답 = 지름길), 드리프트 급커브, NULL 교란 구간(점프·회피), 신호 가속 구간, 결승.
- **정답 차선:** 문제 데이터에서 선택지 순서를 섞어, 정답 차선이 항상 같은 쪽에 오지 않게 했습니다.
- **콘텐츠 분량:** 문제 41개, 도감 25개, 스토리 12개 추가. 문제은행은 전체 64문항, 도감은 9개 챕터 탭.
- **3별 목표 시간:** 깔끔한 주행(드리프트·부스트)으로는 들어오고, 입력 없이 달리면 못 들어오도록 테스트로 조정했습니다.

2. 그래픽 품질 "중간"·"낮음"에서 개선되는지
3. 새 코스 6개의 색·난이도·문제 문구
