- 장식: 배관, 환풍기, 그릴, 유리판, 경광등, CCTV, 휠체어, 들것, 카트, 수액대, 화분, 드럼통, 콘, 경고판, 바리케이드
- **정면·후면 걷기 8프레임** (`walk_front.png`, `walk_back.png`, 프레임당 약 350px): `tools/cut_walk.py`로 개별 분리(흰 헬멧 보존을 위해 외곽선 기준 배경 제거) → 머리 폭·발 위치 기준으로 기존 프레임과 같은 스케일·기준점, 4색 자동 변환. 기존 다리 리그 방식은 제거
- **고해상도 타일** (`tiles_hd.png`, 패널당 약 690px, `tools/build_tiles_hd.py`): 연구실 바닥(3×3 금속판+통풍구), 벽면, **벽 윗면(빔+조명 띠, 가로/세로용)** → 조명 평탄화·가장자리 크로스페이드로 이음새 없는 반복
- **단독 바닥 이미지** (1254px, 이미 반복 가능): 그레이팅 → 복도, 금속판 → 관절 보정실·영상 판독실
- **타이틀 배경 단독 이미지** (1672×941, 확대 없이 사용) + 좌우 어둡게 처리 + 느린 패럴랙스
- 모든 소품: 같은 월드 스케일(캐릭터 키 86 기준), 바닥 기준점(아래 중앙) 통일, 아틀라스 2048×2048 1장

### CHAPTER 2 전용 소품 슬롯 (v8)
`app/public/assets/ch2/props/` 에 PNG를 넣고 `manifest.json` 배열에 키를 적으면(확장자 제외) 게임이 자동으로 그 그림을 씁니다. 비어 있으면 아래 "대체 구성"으로 표시됩니다.

| 키 | 소품 | 권장 규격 | 대체 구성(현재) |
|---|---|---|---|
| `capsule` | 근육 표본 캡슐(빈 유리 캡슐, 내부는 비워 둘 것 — 근육은 게임이 3D 모델 레이어로 넣음) | 투명 PNG, 세로 약 600px, 바닥 중앙 기준, 위에서 비스듬히 본 시점(CH1 소품과 동일) | CH1 캡슐 + 보존액 채움 + 모델 근육 레이어 |
| `capsule_<근육id>` | 특정 근육이 든 완성 캡슐(선택, 예: `capsule_biceps`) | 동일 | — |
| `stimulator` | 전기자극 장치(본체 + 전극 패드·케이블) | 투명 PNG, 세로 약 480px | 기술 장비 + 케이블 + 방전 불꽃 |
| `contraction_rig` | 근수축 실험 장비(근육 고정 클램프·장력계) | 투명 PNG, 세로 약 600px | 이동 카트 + 모델 근육 홀로그램 |
| `anatomy_panel` | 벽걸이 해부도 패널 프레임 | 투명 PNG, 세로 약 380px | 패널 그래픽 + 모델 앞면 해부도 |

- 근육 자체는 그림으로 받지 않습니다. 항상 BodyParts3D 렌더 레이어를 씁니다(해부학 정확성 유지).
- CH1과의 구분: 벽 장미빛 강철 톤(`wallTint`), 바닥 분홍 톤, 분홍 조명, 근육 표본 캡슐·해부도 패널·자극 장치·수축 장비 배치.
