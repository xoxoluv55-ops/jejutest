## 아직 부족한 것 — 추가 제작 필요
| # | 에셋 | 문제 | 필요한 규격 |
|---|---|---|---|
| 1 | **정면·후면 걷기 프레임** | v2 시트도 프레임당 약 55px, 행당 4장(라벨은 8프레임), 다리 변화 거의 없음, 색 변형 불일치(빨강 행 측면 걷기에 파란 헤드폰) → 사용 불가. 현재는 고해상도 정면/후면을 상체·양다리로 나눈 **다리 리그**로 걷기 표현 | **한 장에 한 동작**, 프레임당 세로 **250px 이상**, 6~8장, 기준 색(빨강) 1세트만 있어도 됨(나머지 색은 자동 생성) |
| 2 | 타이틀 배경 고해상도 | 시트 안 이미지라 실제 534×256 → iPad에서 부드럽게 흐림 | **단독 파일** 1920×1080 이상 (시트에 넣지 말고 따로) |
| 3 | 바닥·벽 고해상도 | 시트 안 타일 약 105px (라벨은 512px) → Retina에서 약간 흐림 | **단독 파일** 각 512px 이상 |
| 4 | 벽 윗면(캡) | 없음 → 코드 그림 | 위에서 본 벽 윗면 seamless 1장 |

### 중요: 시트 1장에 모두 넣으면 실제 해상도가 줄어듭니다
이미지 생성기는 1536×1024 한 장 안에 여러 에셋을 넣기 때문에, 라벨에 "512px·1920×1080"이라고 적혀 있어도 실제 각 에셋은 그보다 훨씬 작습니다.
고해상도가 필요한 항목(캐릭터 프레임, 타이틀 배경, 바닥·벽)은 **한 이미지에 하나씩** 생성해 주세요.
