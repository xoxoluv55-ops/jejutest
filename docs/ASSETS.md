- **고해상도 타일** (`tiles_hd.png`, 패널당 약 690px, `tools/build_tiles_hd.py`): 연구실 바닥(3×3 금속판+통풍구), 벽면, **벽 윗면(빔+조명 띠, 가로/세로용)** → 조명 평탄화·가장자리 크로스페이드로 이음새 없는 반복

## 아직 부족한 것
- 필수 추가 제작 에셋 없음 (CHAPTER 1 기준).
- **광배근(latissimus dorsi)**: BodyParts3D 4.0에 포함되어 있지 않아 실제 모델 그림이 없습니다. 지금은 점선 도식(도감)과 작용선(어깨 외전 라운드)으로만 표시하며 화면에도 그렇게 적혀 있습니다. 실제 그림으로 바꾸려면 근육이 분리된 광배근 메시(예: Z-Anatomy, CC BY-SA 4.0 — 라이선스 조건이 달라 확인 필요)나 검증된 해부 일러스트가 필요합니다.
- CH2 환경(방·소품)은 아직 CH1 에셋 재사용 + 분홍 조명입니다(근육 연구실 전용 소품 없음).
- 참고: 타이틀 배경은 1672×941로 요청 규격(1920×1080)보다 약간 작아, Retina iPad 전체 화면에서는 약 1.9배 확대됩니다. 더 선명하게 하려면 같은 그림을 2560×1440으로 다시 받으면 교체만 하면 됩니다(선택).
- 실제 iPad 실기 테스트(성능·터치)는 아직 하지 않았습니다.
