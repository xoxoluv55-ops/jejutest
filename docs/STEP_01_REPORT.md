## 1. Implemented

`MuscleBattle/` — Unity 6 LTS 프로젝트 (Built-in RP + uGUI, 외부 아트 에셋 의존 0).

- **흐름**: Title(PRESS START, 메뉴) → Character Select → VS → Fight(라운드 인트로/FIGHT!) → KO → Victory → Result → 다시 대전/캐릭터 선택/메인 메뉴, 일시정지, 설정. 고유 "muscle fiber slash" 화면 전환.
- **Fighter 2명**: 진현 (Sports PT — 빠른 균형형), 레이 카스티요 (Strength Coach — 느리고 강함, 아머 스페셜, HP 1100). 잠금 슬롯 6개(향후 로스터).
- **Stage**: 스포츠 재활 아레나 — 네온 육각 바닥 + 중앙 엠블럼 + 링아웃 라인, LED 관중벽, 네온 기둥, 천장 라이트 바, 해부학 홀로그램 디스플레이 5개, 회전 홀로그램 인체, 배너, 사인, 라이트 샤프트, 부유 입자. 강타 시 바닥 펄스/홀로그램 글리치.
- **Combat (60Hz 프레임 데이터 상태머신)**: 전진/후퇴/사이드스텝(상대 기준 궤도 이동), 가드(+퍼펙트 가드), 회피(무적 프레임), 약/강/킥, 체인 콤보, 런처→공중 콤보(저글링 감쇠), 잡기(+잡기 풀기), 카운터 자세→퍼펙트 카운터, 카운터 히트, 콤보 데미지 보정, 스페셜(게이지 1칸, 슈퍼 프리즈+컷인), 얼티밋(게이지 3칸, 시네마틱 카메라), 측면/후면 공격은 가드 불가, 아머, 벽 충돌, ADRENALINE(HP 25% 이하 게이지 1.5배), 라운드/타이머/TIME UP/무승부, KO 연출, ANATOMY FINISH.
- **Game Juice**: 등급별 히트스톱(4/6/9/12f, 카운터 +3), 트라우마 카메라 셰이크(설정 0–150%), 줌 펀치, 포커스 샷, 슬로모션(퍼펙트 카운터/스페셜/얼티밋/KO만), 히트 플래시, 스파크/근섬유/플레어/충격파/가드 링/먼지/KO 폭발/차지/승리 컨페티(전부 풀링), 팔다리 트레일, 아드레날린 오라, 화면 플래시.
- **근육 시각화(기초)**: 25개 근육 오버레이(삼각근, 극상근, 대흉근, 승모근, 광배근, 전거근, 코어, 이두/삼두, 둔근, 대퇴사두, 햄스트링, 비복근)가 기술 사용 시 몸 위에 홀로그램으로 점등. 스페셜 컷인/해설에 근육 이름 표시. (근육 *선택* 퀴즈 시스템은 §61에 따라 다음 단계)
- **CPU AI**: 쉬움/보통/어려움 — 반응 확률·지연, 가드/회피/카운터, 콤보 루트, 휘프 응징, 공중 추격, 게이지 사용.
- **2P Local**: 키보드+키보드, 키보드+패드(패드 1개면 2P에게), 패드+패드.
- **UI**: 컨셉 이미지 레이아웃의 HUD(코너 초상화=실제 3D 모델 렌더, 기울어진 HP 바+데미지 트레일, 로고/타이머/라운드 필, 라운드 핍, SPECIAL / EX MUSCLE 3칸 게이지, "N HIT COMBO! 총 데미지", 콜아웃, 스킬 컷인, 해설 바), 캐릭터 선택(정보 패널, 스탯 바, 로스터 그리드, 커서, 락인 연출, 대전 옵션), VS, 결과(점수 카운트업, 배틀 기록, 도전 과제 = CPU 3연승).
- **iPad**: 플로팅 가상 스틱 + 대형 버튼 9개(약/강/킥/가드/회피/잡기/카운터/스페셜/얼티밋, 게이지 부족 시 흐리게), fingerId 단위 소유권으로 버튼↔스틱 입력 분리, 일시정지 버튼, 4:3 화면용 UI 스케일 전환, WebGL 템플릿(줌/스크롤 차단, DPR 1.5 상한), 첫 터치로 WebAudio 잠금 해제, 품질 프로필 Web/iPad 자동 선택.
- **오디오 (전부 오리지널, `tools/generate_audio.py`)**: BGM 7곡(메뉴/선택/VS/배틀/파이널 라운드 레이어(샘플 동기)/승리 스팅/결과), SFX 12종×변형(펀치4·킥3·헤비3·가드3·휘프4 …, 연속 중복 방지+피치 랜덤), UI 사운드 9종, 아나운서 18종(ROUND 1, FIGHT!, COUNTER!, K.O.!, VICTORY!, MUSCLE LINK! …), 음악 더킹, 슬로모션 시 음악 피치 다운.
- **Editor**: 첫 실행 시 씬 생성 + Build Settings + WebGL 설정 자동, `MUSCLE BATTLE` 메뉴(씬 열기, WebGL/Windows 빌드), 배치 빌드 메서드.

## 2. Combat Test

**이 세션에서는 Unity 에디터를 실행할 수 없어 실제 플레이 테스트를 하지 못했습니다.** (클라우드 컨테이너에 Unity 설치/라이선스 없음)
대신 한 것:
- 프레임 데이터/상태 전이/히트 판정/콤보 보정/KO 흐름을 코드 리뷰로 점검 (잡기 후 피해자 위치 고정 버그 등 수정).
- 첫 Unity 실행에서 확인할 체크리스트:
  1. 약→약→약, 약→강, 킥→킥(런처)→약 공중 추격이 이어지는가 / 콤보 카운터·데미지 표시
  2. 사이드스텝으로 직선기 회피, 측면 히트는 가드 불가
  3. 퍼펙트 가드(직전 가드), 카운터 자세→퍼펙트 카운터 슬로모션, 잡기→잡기 풀기
  4. 스페셜/얼티밋 게이지 소모, 슈퍼 프리즈, 컷인, 근육 홀로그램 점등
  5. KO → ANATOMY FINISH/ K.O. → 승리 포즈 → 결과 화면, 라운드 3판 2선승, TIME UP
  6. CPU 3단계 난이도 체감, 2P 키보드+패드
  7. "근육 문제가 하나도 없어도 이 전투가 재미있는가?" (§62 첫 번째 질문)

- Editor 스크립트: UnityEditor 참조 어셈블리로 컴파일 → **0 errors, 0 warnings**.
