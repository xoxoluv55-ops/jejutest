# STEP 02 보고서 — Shoulder Abduction Muscle Skill 실제 구현

사용자 지시(우선순위 1)에 따라 **Muscle Skill 1개(어깨 외전)** 만 완성했습니다. 다른 근육 문제는 추가하지 않았습니다.

## Implemented

**발동**: 진현으로 스페셜(Muscle Skill) 버튼을 누릅니다 (게이지 1칸 필요).
- 키보드: `I`
- 패드: `RB`
- iPad: `스페셜` 버튼
- 콤보 히트 중 스페셜 캔슬로도 발동됩니다.

**진행 순서**
1. **선택 단계**
   - 시간이 time scale 0.25로 느려집니다. 전투가 완전히 멈추지는 않습니다.
   - 진현은 기술 준비 자세로 고정되고, 이때는 맞지 않습니다.
   - 상대가 이미 경직 중이거나 공중에 떠 있으면 그대로 고정되므로, 콤보가 끊기지 않습니다.
   - 라운드 타이머는 멈춥니다.
2. **카드 UI**: 화면 중앙 하단에 큰 카드 4장이 나옵니다. 중앙을 가리는 큰 패널은 없습니다.
   - 카드 구성: 버튼 표시(J/K/L/SPC · X/Y/A/B), 작은 해부도(뒤에서 본 오른쪽 어깨, 해당 근육만 빨간 근섬유로 표시), 한글명, 영문명
   - 카드: 가시위근 / 어깨세모근 / 큰원근 / 넓은등근
3. **선택 방법**
   - 키보드·패드: 공격 버튼 4개(약/강/킥/회피)가 각 카드에 대응합니다.
   - 터치: 카드를 직접 탭합니다. 카드 크기는 290×220(iPad 기준 약 150pt)입니다.
   - 카드가 떠 있는 동안 터치 공격 버튼은 꺼집니다. 버튼과 카드가 겹쳐서, 카드를 누를 때 공격이 같이 나가는 것을 막기 위해서입니다.
   - 고른 카드는 글로우 + 외곽선으로 표시됩니다.
   - 2개를 고르면 자동으로 확정됩니다. 제한시간은 4초이고, 처음 할 때(학습 단계)는 6초입니다.
4. **판정**

| 결과 | 조건 | 효과 |
|---|---|---|
| PERFECT MUSCLE LINK! | 둘 다 정답 + 2.2초 이내 | 데미지 ×1.5, 러시 +1타(콤보 연장), 게이지 30 회복, 금색 플래시, 스테이지 펄스, 근섬유 트레일 |
| MUSCLE LINK! | 둘 다 정답 | 데미지 ×1.25, 근섬유 트레일 |
| PARTIAL LINK | 1개 정답 + 1개 오답 | 기본 스킬, 보너스 없음 |
| MUSCLE LINK FAILED | 정답 0개 또는 시간 초과 | 데미지 ×0.6 약한 스킬. 공격 자체는 나갑니다 |

5. **정답 후 연출 (Knowledge → Muscle Visualization → Attack)**
   1. 몸 위의 가시위근 → 어깨세모근 홀로그램이 차례로 켜집니다.
   2. 각 근육에서 팔(공격하는 손)로 에너지 빔과 입자가 모입니다.
   3. 손에서 플래시가 터집니다.
   4. "MUSCLE LINK!" 또는 "PERFECT LINK!" 아나운서가 나옵니다.
   5. 마지막으로 공격이 나갑니다.
6. **해설 바**: 정답과 이유를 짧게 보여줍니다. 예: "가시위근이 외전을 시작(초기 약 15°), 어깨세모근 중간섬유가 이어받음 / 큰원근·넓은등근은 내전·신전".
7. **학습 단계 (§18)**: 문제를 처음 볼 때(LEARN)는 정답 카드에 ★ 표시가 붙습니다. 두 번째(PRACTICE)에는 힌트 1개, 세 번째부터(RECALL)는 힌트가 없습니다. 진행 상황은 PlayerPrefs에 저장됩니다.
8. **CPU 진현**: CPU가 쓸 때는 카드가 OBSERVE 모드로 보여서 정답을 같이 맞혀볼 수 있습니다. 정답률은 난이도별로 45% / 72% / 90%입니다.
9. **결과 화면**: 배틀 기록에 머슬 링크 횟수와 그중 PERFECT 횟수가 추가됐습니다.

**함께 고친 것**
- 콘솔 경고 `Look rotation viewing vector is zero`를 고쳤습니다. 첫 프레임에 카메라 방향이 0이 되는 문제였습니다.

**범위 밖으로 둔 것**
- 레이 카스티요의 스페셜과 양쪽 얼티밋에는 아직 근육 문제가 없습니다. Shoulder Abduction 하나만 먼저 완성한다는 지시에 따른 것입니다.
