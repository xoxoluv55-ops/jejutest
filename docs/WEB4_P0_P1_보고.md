# NERVE RUNNER v4.0 — 1차 작업 보고 (P0 성능 + P1 레이싱 개편 + 챕터 전용 미션)

기준 코드: `web/src/*` (공유 링크의 HTML을 만드는 원본). 첨부 HTML은 대화에 업로드되지 않아 저장소 원본으로 작업함.
의존성: three.js r160 ES 모듈 + 후처리(EffectComposer/UnrealBloom) — `cdn.jsdelivr.net`에서 로드, **첫 실행에 인터넷 필요**. 글꼴 Jua(Google Fonts, 실패 시 시스템 글꼴). 그 외 외부 리소스 없음(음악·효과음은 코드로 합성).

## 1. 기존 구조 분석 (의존관계)
`NR_CONTENT`(문제·도감·스토리 JSON) → `NR.Bank`/`shuffledBank()` → `stage.build(bank)`(core.js 레이아웃 → TrackGraph) → `buildWorld()` → `NRW.build()`(world.js 메시) → `startStage()`(레이스 상태) → 대화 → `startCountdown()` → `frame()` 루프(`tickRace` → `sim.step` 서브스텝 → `handle()` 이벤트 → HUD/음성/FX → `world.update` → render). 저장: `localStorage["nerverunner_web_v1"]` 단일 JSON, 버전 필드 `v`로 마이그레이션.

## 2. P0 성능 — 원인과 수정
| 문제 | 원인 (측정/분석) | 수정 |
|---|---|---|
| 카운트다운 2초 부근 멈칫 | 스테이지 시작 직후 첫 렌더에서 셰이더 컴파일·텍스처 업로드 스파이크(헤드리스 측정: 533·317·150 ms). iOS는 물체가 처음 화면에 들어올 때 컴파일 → 카메라가 별 뒤로 도는 "2" 무렵 | 스테이지를 "구간 준비 중" 화면 뒤에서 만들고 `renderer.compile()` + 모든 텍스처 `initTexture()` + 1프레임 미리 렌더 후 시작. 카운트다운을 실제 시계(performance.now) 기준으로 |
| 시작 시 음악 버퍼 합성 | 레이스 음악(약 32만 샘플)을 시작 순간 합성 | 첫 터치 후 메뉴 화면에서 미리 합성 |
| 주행 중 불규칙 끊김 | 매 프레임 객체 생성(별·카메라·FX의 Vector3/Quaternion/Matrix4, 이온 입자 경로 계산) → GC 멈춤 | `frameAtInto()` 재사용 객체, 카메라 스크래치 벡터, 이온은 재생성 때만 계산(3.0), 오브 정적 행렬(3.0) |
| 드로우콜 과다 | 1프레임 292 드로우콜·삼각형 120k (성능 표시로 측정) | EPSP/IPSP 개별 스프라이트 → 종류별 Points 1개, 모바일 시야거리 250 m(가볍게 190 m) → **165 드로우콜·85k** |
| 렌더 vs 조작 | — | 설정 › 프레임 제한 "30 FPS 안정": 화면만 30fps, 입력·물리는 매 프레임 |
| 지표 | — | 설정 › 성능 표시: FPS, 평균/최대 프레임 시간, 렌더 시간, 드로우콜, 삼각형, 지오메트리·텍스처·셰이더 수, JS 힙(지원 브라우저), 화질·DPR |
기존 유지: 폰·태블릿 블룸 끔, FPS 감시 자동 화질 하향, DPR 상한(폰 1.3), 160 m 칸 단위 컬링, HUD 변경 시에만 DOM 갱신.

## 3. P1 레이싱 개편 (core.js `piece()` + world.js 시각화)
| 요소 | 규칙 |
|---|---|
| 고속 직선 | 부스트 패드 3개(밟으면 터보 1.3초) + 오브 라인 |
| S자 커브 | 좌-우-좌 연속 커브, 오브가 레이싱 라인을 따라 배치 |
| 점프대 | 밟으면 높이 약 5 m 도약 → 바로 뒤 파동 장애물을 넘음 |
| 움직이는 NULL 블록 | 좌우 왕복(진폭 ±6 m, 속도 제각각), 바닥에 이동 범위 표시 |
| 레이저 장벽 | 1.6–1.8초 주기로 켜짐/꺼짐, 켜지기 0.35초 전 예고 깜빡임 — 켜져 있을 때 점프 또는 꺼질 때 통과 |
| 좁은 통로 | 폭 절반 이하, 오브 일렬 |
| 드리프트 충전 구간 | 바닥 주황 줄무늬, 드리프트 충전 ×1.8 |
| 결절 링 콤보 | 3연속 소형 부스트, 5연속 강력 부스트, 10연속 SUPER COMBO(에너지 가득), 놓치면 초기화, 정중앙(±0.7 m) PERFECT 추가 점수 |
| 위험/보상 갈래 길 | 문제 없는 갈림길: 안전(오브 4) vs 위험(레이저·움직이는 블록 + 오브 14). 학습 정답과 무관 |
| 충돌 | 속도 감소 + 신호 에너지 −12% (블록·레이저·움직이는 블록 공통) |
| 미리 인지 | 모든 구간 입구에 주황 안내 홀로그램 + 급커브 화살표(3.0) |

## 4. 챕터별 전용 미션
| 챕터 | 미션 | 학습 내용 |
|---|---|---|
| 1 뉴런 | 결절 링 SUPER COMBO(19개 링), EPSP 가중, 점프대·움직이는 블록 구간 추가 | 도약전도·활동전위 재생성 |
| 2 척수와 반사 | **척수반사 긴급 미션** ×2: 자극(🔨/📌/✋) → 신장반사=부스트, 굽힘반사=점프(압정 넘기), 교차폄반사=반대쪽으로, 상호억제=아무것도 누르지 않기. 결과마다 반사 경로 한 줄 해설. "실제 반사는 수십 ms" 고지 | 반사궁 4종 |
| 3 오름로·내림로 | **신경 교차 드리프트** ×3(DCML·앞가쪽계·겉질척수로): 층마다 신호가 지나가는 쪽 차선으로 이동 | 교차 위치 |
| 4 뇌줄기 | **신경핵 층 포털**: 중간뇌/다리뇌/숨뇌 층에 있는 신경핵 차선 고르기 | 뇌신경핵 위치 |
| 5 소뇌 | **소뇌 균형 라인** ×2: NULL이 몸을 흔드는 동안 빛나는 선 위 60% 이상 유지 + 드리프트 충전 구간 ×2 | 운동 오차 보정 |
| 6 사이뇌 | **시상 중계 포털**: 감각 신호를 LGN/MGN/VPL/VPM/VL로 보내기 | 시상 중계핵 |
| 7 대뇌 | **대뇌 기능 포털**: 명령(말하기·이해·보기…)에 맞는 겉질 영역 | 기능 국재 |
| 8 12뇌신경 | **뇌신경 포털**: 동작에 맞는 뇌신경 | 뇌신경 기능 |
| 9 NULL | 반격 구간에 레이저·움직이는 블록 추가(보스 1페이즈 액션 일부) | — |
포털 문항은 판마다 4개 무작위·보기 순서 섞음. 기존 문제은행·해설·정답 판정은 그대로.
