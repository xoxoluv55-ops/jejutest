# CH1 탐험 구역 개편 (v0.5) — 탐험 · 잠입 · 생존 · 퍼즐 · 탈출

이번 단계에서는 **CH1 하나의 구역을 처음부터 끝까지 실제로 플레이할 수 있게** 만들었습니다. CH2는 공통 시스템(하트·피해·체크포인트·카메라·HUD)만 함께 바뀌었고, 경비 드론·레이저·퍼즐 연동은 아직 CH2에 넣지 않았습니다.

## 1. 뼈마다 다른 획득 과정
이제 뼈는 **직접 다가가면 회수**됩니다. 손 버튼은 보관함이나 장치를 열 때만 씁니다.

| 뼈 | 장소 | 획득 과정 | 실패 조건 |
|---|---|---|---|
| 어깨뼈 Scapula | B-02 격리 통로 | SCAN을 하기 전에는 보관함이 보이지 않습니다. SCAN으로 찾은 뒤 엽니다. | 없음 (탐색) |
| 위팔뼈 Humerus | V-05 표본 보관동 (신규) | 경비 드론의 순찰과 시야를 피해 북쪽 캡슐까지 갑니다. 캡슐을 열면 소음 때문에 드론이 그쪽을 의심합니다. | 발각·추격 중 접촉하면 하트 −1 |
| 카드키 S-07 | V-05 순찰 경로 안쪽 | 드론의 순찰 루프 안에 떨어져 있습니다. | 위와 같음 |
| 노뼈 Radius (+심화: 종아리뼈) | S-07 잠금 보관실 (신규) | 카드키로 문을 엽니다. 안쪽 바닥 배선이 주기적으로 방전합니다. | 방전에 닿으면 하트 −1 |
| 빗장뼈 Clavicle | L-06 레이저 통로 (신규) | 세 종류의 레이저 사이를 지나갑니다: 깜빡이 레이저, 위아래로 움직이는 레이저, 좌우로 움직이는 레이저 쌍. | 레이저에 닿으면 하트 −1 |
| 자뼈 Ulna | L-06 맨 끝 받침대 | 집는 순간 보안 경보가 울립니다(붉은 조명, 추격 음악). 레이저가 1.3배 빨라지고 출구에 셔터 레이저가 켜집니다. **기초 45초 / 심화 28초** 안에 서쪽 출구로 나가야 합니다. | 시간이 지나면 셔터에 갇혀 하트 −1, J-03 체크포인트로 돌아갑니다. 자뼈는 그대로 가지고 있습니다. |

**보급 상자**는 기초 5개, 심화 3개입니다. 열면 다음 중 하나가 무작위로 나옵니다.
- 회복 앰플: 하트 +1
- 일회용 보호막: 다음 피해 1번을 막습니다
- 스캐너 증폭기: 다음 SCAN의 탐지 반경이 2배가 됩니다

하트가 가득 찬 상태에서 회복이 나오면 보호막으로 바뀝니다.

## 2. 하트 · 피해 · 체크포인트
- **하트와 피해**
  - 하트 3개로 시작합니다.
  - 경비 드론, 레이저, 방전 배선, 증기, 셔터에 닿으면 하트 1개를 잃습니다.
- **피격 연출**
  - 1.5초 동안 무적이 됩니다.
  - 캐릭터가 깜빡이고, 화면이 흔들리고, 붉게 번쩍이며, 효과음이 납니다.
  - HUD의 하트 칸이 튀어 오릅니다.
- **체크포인트**
  - 위치: B-02, A-01, J-03, X-04.
  - SAVE 발판을 밟으면 저장됩니다.
- **하트 0개일 때**
  - 화면이 어두워진 뒤 마지막 체크포인트로 돌아갑니다. 하트는 3개로 채워집니다.
  - 회수한 뼈, 카드키, 학습 기록은 그대로 유지됩니다.
  - 경비 드론은 순찰 시작 위치로 돌아갑니다.
- **피할 수 있게 하는 장치**
  - 레이저는 켜지기 0.6초 전에 노란 점선으로 깜빡입니다.
  - 드론의 시야는 바닥에 빛 원뿔로 보입니다. 벽과 상자에 가려진 부분은 원뿔에서 잘려 나갑니다.

## 3. 경비 드론 AI
- **상태 변화:** 순찰 → 의심 → 발견 → 추격 → 수색 → 복귀 → 순찰
- **시야:**
  - 시야 거리: 기초 185, 심화 245 (추격·수색 중에는 1.25배)
  - 시야각: 기초 56°, 심화 68°
  - 벽과 소품(상자·랙 등)의 사각형이 시선을 막습니다.
- **의심:**
  - 시야 안에 있으면 의심 게이지가 찹니다. 가까우면 2.2배 빠르게 찹니다.
  - 시야에서 벗어나면 게이지가 줄어듭니다.
  - 게이지가 가득 차면 "!" 표시, 경보음, 추격 음악이 나옵니다.
- **추격과 수색:**
  - 추격 중에는 마지막으로 본 위치로 따라옵니다.
  - 놓치면 그 자리에서 4초 동안 좌우를 살핀 뒤 순찰로 돌아갑니다.
- **숨기:**
  - 엄폐물: 보관동의 상자 두 줄과 랙.
  - 사물함(V-05 2개, A-01 1개)에 숨으면 드론이 보지 못합니다.
  - 추격당하는 중에는 사물함에 들어갈 수 없습니다.
- **배치:** 기초는 보관동에 드론 1대입니다. 심화는 출입구 쪽 드론 1대가 더 있고, 최종 탈출 때 A-01에도 1대가 나옵니다.

## 4. 카메라 · HUD
- **카메라 배율:** iPad 가로 기준 1.08 → 1.72 (약 1.6배)
  - 휴대폰 가로처럼 짧은 화면에서는 조금 덜 확대합니다(최소 1.34).
  - 카메라는 부드럽게 따라옵니다(보간 0.09).
- **화면 밖 위험 표시:** 화면 밖 위험 요소를 화면 가장자리에 표시합니다.
  - 드론: 노랑(의심 중이면 빨강, 깜빡임)
  - 레이저: 분홍
- **미션 창:** 기본은 진행 중인 미션 한 줄만 보입니다. 누르면 전체가 펼쳐집니다. 카메라 확대로 가려지는 화면을 줄이기 위해서입니다.
- **하트 표시줄:** 미션 창 아래에 하트, 보호막, 카드키를 표시합니다.
- **안전 영역:** 홈 표시줄 영역은 v0.4부터 `#game`이 피해서 그립니다(`env(safe-area-inset-*)`).

## 5. 퍼즐 → 연구실 변화
- **뼈대 조립 성공**
  - 회수한 뼈 5개가 캐릭터에게서 복구 테이블로 날아갑니다.
  - 팔뼈대 순서(빗장뼈·어깨뼈 → 위팔뼈 → 노뼈·자뼈)대로 눕혀 맞춰지고, 홀로그램이 떠오릅니다.
  - 이어서 기존의 정전 이벤트가 시작됩니다.
- **관절 정렬 성공**
  - J-03 보정 장치 위의 관절 모델이 움직입니다(어깨 벌림 → 팔꿈치 굽힘).
  - 장치의 기계 팔이 X-04 출입문을 끌어 엽니다.
  - 이전에는 전원 복구만으로 문이 열렸습니다. 이제는 관절 정렬을 해야 열립니다.
- **X-ray 판독 성공**
  - X-04에 조명이 켜지고 게이트 잠금 3이 풀립니다.
  - 3초 뒤 **최종 탈출 이벤트**가 시작됩니다.
    - 보안 시스템이 다시 켜지고 붉은 경보와 추격 음악이 나옵니다.
    - 게이트 앞에 레이저 2줄이 켜집니다.
    - 제한 시간: 기초 130초 / 심화 80초. 심화는 A-01에 드론이 추가됩니다.
  - 시간이 지나면 하트 −1, 체크포인트로 돌아가 다시 도전합니다.
- **해부학 학습:** 뼈를 회수할 때 그 뼈가 무엇인지 한 줄로 알려 줍니다(기초만). 심화는 이름만 표시합니다.
- **해부학 데이터:** 기존 퍼즐의 학습 데이터와 판정은 바꾸지 않았습니다.

## 7. 그래픽에 대해 (정직하게)
- **코드로 그린 그래픽:** 경비 드론, 보급 상자, 카드키, 레이저 발사기, SAVE 발판은 `art/stealth.ts`에서 캔버스로 그렸습니다. 일러스트 수준은 아닙니다. `public/assets/art/<키>.png`로 교체할 수 있습니다.
- **선 효과:** 레이저 빔과 시야 원뿔은 그래픽 선과 면입니다.
- **기존 에셋:** 사물함(숨기)과 상자(엄폐)는 기존 일러스트 에셋(env 아틀라스)을 썼습니다.
