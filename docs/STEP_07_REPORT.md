# STEP 07 — MUSCLE BATTLE 2.0: 실제 3D 캐릭터 + 애니메이션

## 1. 실제 3D 모델 (플레이 가능한 캐릭터)
- `Resources/Characters/jin.fbx`, `ray.fbx` — Unity Humanoid 리그, 사실적인 근육 인체 메시(Quaternius Universal Base Characters "Superhero_Male", CC0).
- 진: 파란 트렁크·검은 머리, 몸통/다리 7% 더 두껍게. 레이: 빨간 트렁크·보라 머리, 3% 더 날씬하게.
- 캐릭터 선택, 전투, HUD 초상화, 근육 퀴즈 카드에 모두 적용됨 (Unity Play Mode에서 확인).

## 2. 남아 있는 임시 모델
- 잠긴 로스터 실루엣(locked_1~5)은 그대로 실루엣. 캡슐/큐브 캐릭터는 진·레이 모델이 없을 때만 쓰는 예비 경로로 남음.

## 3. 구현된 애니메이션 (실제 클립, 프레임 데이터와 동기화)
대기(격투 자세+호흡), 등장, 앞/뒤 걷기, 좌/우 사이드스텝(상체 가드 유지 합성), 가드, 회피, 피격(약/강), 넉다운, 일어나기(진: 누운 자세에서 일어나기, 레이: 킥업),
승리, 패배, 잽, 크로스, 훅(+회수), 어퍼컷, 프론트킥, 니킥(레이 h1), 킥 계열, 숄더 대시(진 스페셜), 연속기(레이 스페셜, 궁극기).
공격 클립은 타격 시점(42%)이 기술의 첫 판정 프레임과 맞도록 재생 시간을 맞춤.

## 4. 아직 없는 애니메이션 (코드로 만든 자세가 대신 재생)
내려찍기(진 h1·퍼펙트 카운터), 잡기·던지기·잡힌 상태, 카운터 자세, 캐릭터 선택 화면 동작(팔짱·호버·락인은 기존 코드 동작을 새 모델에 적용).
피격 클립은 양손이 내려간 기본 자세에서 시작해 격투 자세와 이어짐이 약간 어색함.

## 5. 텍스처와 머티리얼
- 몸 1024² 알베도+노멀, 머리 512², 눈 512². iPad/WebGL은 ASTC 6x6, 최대 1024.
- 머리카락은 알파 컷아웃, 피부 광택 0.32. 피격 섬광(_EMISSION)과 X-RAY(어두운 스캔 실루엣) 적용 확인.

## 6. 게임 안에서 확인한 결과
- CPU vs CPU(디버그 F7)로 실제 전투 재생: 펀치·킥·훅, 가드, 걷기, 넉다운, 승리 동작 확인. 오류 0.
- 근육 링크: 상대 몸이 X-RAY 실루엣으로 바뀌고 해부 태그와 함께 궁극기 연출 확인.

## 7. iPad WebGL 성능
- 이번 단계에서 iPad 실기 측정은 하지 않음. 클립 48개 약 18MB(FBX, 임포트 후 Optimal 압축), 캐릭터 2명 FBX 각 1.1MB.
- 스킨 2본 가중치, 오프스크린 업데이트 끔. 다음 단계에서 WebGL 빌드 후 iPad Safari로 FPS 측정 필요.

## 8. 필요한 외부 자산/도구
- 현재 자산은 모두 CC0(출처: Characters/CREDITS.txt). 재생성: `tools/character_build/` (Blender 4 스크립트).
- 내려찍기·잡기·던지기·회축 등은 Mixamo(무료 Adobe 계정)에서 받아 `{id}_anims/{키}.fbx`로 넣으면 자동 적용.

## 추가 — 근육 내용 교재 기준 정리 (서연님 교재 자료 = MyoForge `scripts/fullbody/textbook/tb.tsv`)
- 용어: 삼각근·극상근 → 어깨세모근·가시위근, 위/아래등세모근 → 등세모근 위부분/아래부분, 엉덩허리근 → 큰허리근, 뒤넙다리근(묶음) → 반막근·반힘줄근·넙다리두갈래근.
- 작용 문구를 교재 표현으로: 위팔의 벌림/가쪽돌림, 넙적다리의 폄·굽힘, 종아리의 폄·굽힘.
- 해설 수정: 큰원근 = 모음·안쪽돌림(교재), 큰마름근 = 어깨뼈 모음·올림(교재, "아래쪽돌림" 삭제), 가시위근 "초기 15°" 삭제, 신경 뿌리(C5–C6) 삭제(교재에 없음).
- 앞톱니근 위쪽돌림은 교재('어깨뼈의 내림(벌림)')에 없는 표준 해부학 내용 → 교수님 확인 대기(MyoForge ANATOMY_REVIEW_41 #8).
- 근육 카드/X-RAY 위치: 큰허리근·중간볼기근·큰원근·작은원근·어깨밑근·큰마름근·넙다리곧은근·가쪽넓은근·넙다리두갈래근·안쪽 뒤넙다리근·등세모근 위/아래부분을 각자 실제 위치에 따로 표시.
